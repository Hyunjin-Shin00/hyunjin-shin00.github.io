초소형 위성 전처리 및 포인팅 오차 분석CubeSat Preprocessing & Pointing Error Analysis

2025.03 – 2026.05 · 주 담당Lead · 완료Completed
복사보정검보정PRNU통계분석

자사 초소형 위성의 원시 바이너리를 영상으로 바꾸는 파이프라인을 만들고, 촬영 위치가 왜 어긋나는지를 궤도·자세 메타데이터로 통계 분석했다.Built the pipeline that turns our CubeSat's raw binary into imagery, then statistically traced why its pointing drifts, using orbit and attitude metadata.

배경 · 목표Background

  • 자사가 운용하는 초소형 위성의 L1A 데이터 품질 검증이 필요했다.
  • 이진 원시 데이터에서 RGB 영상까지 가는 전처리 자동화가 없었다.
  • 포인팅 오차, PRNU(픽셀 비균일성), 색감 이상 등 센서 품질 이슈를 체계적으로 봐야 했다.
  • The L1A data quality of our in-house CubeSat needed verification.
  • There was no automated path from raw binary to RGB imagery.
  • Sensor quality issues — pointing error, PRNU, colour anomalies — needed a systematic look.

방법Method

  • 이진 원시 데이터 → GeoTIFF → RGB PNG 전처리 자동화 파이프라인 구축 (배치 쉘 스크립트 연동).
  • DN → Radiance → TOA Reflectance 복사보정 체인 구현.
  • 위성 제조사가 제공한 궤도·자세 메타데이터와 실제 포인팅 오차를 매칭 (전체 65건, 텔레메트리 보유 27건).
  • Pearson · Spearman · Kendall 세 가지 상관계수를 함께 사용 — 표본이 27건으로 적을 때 Kendall의 p-value가 더 안정적이기 때문.
  • along / across / total 방향별로 오차를 분해해 각각의 원인 파라미터를 찾았다.
  • 이상치 그룹과 정상 그룹의 파라미터 분포를 boxplot으로 비교.
  • PRNU 보정 전후 영상 품질 비교 분석.
  • Built an automated raw-binary → GeoTIFF → RGB PNG pipeline, driven by batch shell scripts.
  • Implemented the DN → radiance → TOA reflectance radiometric chain.
  • Matched measured pointing error against orbit and attitude metadata from the manufacturer (65 scenes total, 27 with telemetry).
  • Used Pearson, Spearman and Kendall correlations together — with n=27, Kendall's p-value is the more trustworthy one.
  • Decomposed error into along / across / total components and hunted the driving parameter for each.
  • Compared parameter distributions between outlier and normal groups via boxplots.
  • Compared image quality before and after PRNU correction.

결과Results

  • 전처리 자동화 파이프라인 완성 — binary에서 PNG까지 원스텝
  • 경과일(시간 드리프트)이 along·across·total 모든 오차 유형과 유의한 상관을 보이는 유일한 변수임을 확인 (n=65, along r=0.586 p<0.0001)
  • across 오차는 Tilt(roll) 각도와 음의 상관 (r=−0.322, p=0.0089) — 자세 제어의 영향
  • 텔레메트리 보유 27건에서 GNSS-TLE 고도차 |Δalt|가 along·total 오차와 유의한 상관 (r=0.534 / 0.552)
  • 이상치 그룹과 정상 그룹 사이에 통계적으로 유의한 파라미터 차이는 발견되지 않음 — 단일 원인으로 설명되지 않는다는 결론
  • A one-step pipeline from raw binary to PNG.
  • Found elapsed time since start to be the only variable significantly correlated with all three error types (n=65; along r=0.586, p<0.0001).
  • Across-track error correlates negatively with tilt/roll angle (r=−0.322, p=0.0089), pointing to attitude control.
  • In the 27 telemetry scenes, GNSS–TLE altitude mismatch |Δalt| correlates with along and total error (r=0.534 / 0.552).
  • No statistically significant parameter difference between outlier and normal groups — so the outliers are not explained by a single cause.

배운 점 · 한계What I learned · Limitations

  • 초소형 위성 복사보정 파이프라인을 처음부터 끝까지 이해했다.
  • 표본이 작을 때 어떤 상관계수를 믿어야 하는지 — Kendall τ가 n이 20대일 때 왜 더 나은지 — 를 실제 판단 근거로 썼다.
  • '유의한 차이가 없다'도 결론이라는 것. 이상치의 원인을 찾지 못했다는 사실 자체를 보고에 명시했다.
  • 한계: PRNU 보정 알고리즘 최적화는 추가 연구 여지가 남아 있다.
  • Understood a CubeSat radiometric calibration pipeline end to end.
  • Used the choice of correlation statistic as a real decision — why Kendall's τ is the safer read at n≈27.
  • Learned that 'no significant difference' is also a finding, and reported the failure to explain the outliers rather than hiding it.
  • Limitation: the PRNU correction algorithm still has room for optimisation.
