Executive summary

SkySat 위성영상(0.5 m, 4밴드)에 기반한 이 리포트는 총 30,558개의 OSM 건물 폴리곤을 세 단계로 분류합니다: 완전 파괴 151개 (0.49%), 부분 파괴/영향 2,742개 (8.97%), 영향 적음/없음 27,665개 (90.53%). 두 개의 상호 보완적 분류기 — Gradient Boosting Trees(GBT, 완전 파괴 담당)와 Logistic Regression(LR, 확장 감지 담당) — 이 v7 파이프라인 안에서 결합되어 검증(hand-labeled 86 damaged + 75 intact)과 약한 감독(MS AI for Good 라벨 필터링) 을 조합해 학습되었습니다.

모델은 정직한 5-fold 교차검증에서 GBT AUC 0.7633, LR AUC 0.8357, LR PR-AUC 0.8766를 기록했으며, 관측각도/기하정합 오차를 보정하는 v2 파이프라인과 사람 검수 hard-negatives 75개 도입을 통해 이전 버전 대비 PR-AUC를 10배 이상 개선했습니다.

Methodology

1. 데이터 소스

  • Post 영상: 20260627_112621_ssc2_u0001_pansharpened.tif (SkySat, off-nadir 29.3°, view az 41.5°, sun el 16.8°)
  • Pre 영상: 20260521 (SkySat, off-nadir 29.1°, view az 356.1°) 우선, 20260211 (SkySat, off-nadir ~5°, view az 106.5°) 보조
  • 건물 폴리곤: OpenStreetMap (osm.fgb, 37,165 buildings)
  • 약한 감독 라벨: Microsoft AI for Good (ALL_AOIS_building_predictions_deduplicated.gpkg, 8,410 damaged flags across 72,162 buildings)
  • 사람 라벨: damaged.gpkg (33) + damaged2.gpkg (53) = 86 hand-damaged, review_candidates_negative_v2.gpkg = 75 hand-intact hard negatives

2. 파이프라인 개요

  1. Polygon-TIF 매칭: 폴리곤이 기준 TIF 유효 데이터 영역에 완전 포함되고, 최소 1장의 pre-TIF에 겹치는 것만 분석 대상 (31,008 → 30,558 v2-analyzable)
  2. 기하 보정 (v2): 각 폴리곤에 대해 phase correlation으로 pre-post 서브픽셀 정렬 → 1 m inward buffer로 벽/경계 제거 → Otsu 기반 실제 건물 segmentation → 관측각도 차이로 인한 로프 shift 완화
  3. Feature 추출: 4밴드 평균, 밝기, NDVI/NDWI/NDYI, 밴드 비율(G/R, NIR/R), GLCM 텍스처(std, gradient, contrast, homogeneity, energy) — pre와 post에 대해 각각, 그리고 change ratio/difference
  4. 학습: MS의 Planet-confirmed 양성 필터링(Vantor-only ~2,600 FP 제거) + MS==0 & num_obs≥2 & unc==0 hard-negative pool(6,246) + 사람 라벨 (86 pos + 75 neg, w=5) → LR (class_weight=balanced) + GBT (200 트리, depth=3) 학습, 5-fold CV
  5. 임계값 선택: LR은 Youden's J on OOF (0.618), GBT는 hand-pos 90% recall 기준(0.5)
  6. 3-tier 분류: GBT ≥ 0.5 → 완전 파괴, LR ≥ 0.618 & GBT < 0.5 → 부분/영향, 나머지 → 영향 적음

GBT는 학습된 결정 트리들이 특정 조건 조합을 만족할 때만 강한 양성 점수를 부여합니다. 이는 확신하는 완전 파괴 케이스에 이상적이며, 경계 케이스는 자연스럽게 낮게 나옵니다. 반대로 LR은 각 feature의 선형 가중합으로 부드러운 확률을 산출하므로 부분 파괴/영향처럼 완전 파괴 신호는 약하지만 여러 지표가 미묘하게 이상한 케이스를 잡아냅니다. 두 모델을 합쳐 사용하면 완전 파괴는 GBT가 담당하고, 부분 영향은 LR이 커버합니다.

4. 사용된 v7 최종 feature (6개)

  1. v2_post_std_abs — post 영상 픽셀 표준편차 (붕괴 시 표면 거칠어짐)
  2. v2_post_grad_abs — post Sobel gradient 평균 (엣지/파편)
  3. v2_d_grad_ratio — post/pre gradient 비율 (지붕 파괴로 엣지 증가)
  4. v2_post_contrast_abs — post GLCM contrast
  5. v2_d_BRIGHT_ratio — post/pre 4-band 평균 비율 (콘크리트/잔해 노출)
  6. v2_d_homogeneity_diff — GLCM homogeneity 변화 (표면 균일성 변화)

Score 분포

Caveats and limitations

  • Hand-label leakage: 86 hand-damaged과 75 hand-intact이 학습에 포함되었으므로 in-sample confusion 수치는 낙관적. 실제 일반화 지표는 5-fold CV AUC (LR 0.84, GBT 0.76)를 참조.
  • 관측각 차이: 0627 (off-nadir 29.3°)과 0521 (29.1°)은 tilt 크기 유사하나 view azimuth 차이 45°가 있어 건물이 다른 방향으로 leaning. v2 phase-correlation 정렬 + Otsu segmentation이 이를 부분적으로 보정하나 완벽하지 않음.
  • MS 라벨 노이즈: MS의 Vantor-only 양성(~2,600) 및 MS==0 중 hidden damage (~10-30%) 고려됨. Planet-confirmed 필터 + HCI(MS==0 & num_obs≥2 & unc==0) 조건으로 완화하였으나 잔존 noise 있음.
  • OSM 폴리곤 커버리지: OSM에 등록된 건물만 분석 대상. 미등록 건물은 제외.
  • 정밀도 상한: 86 hand-pos는 여전히 작은 샘플. 100~300으로 확대 시 GBT 성능 추가 향상 가능.
  • 일반화: 이 v7 모델은 Maiquetia 지역 학습. 다른 지역 적용 전에 관측각/조도 차이 큰 경우 재보정 권장.

Reproduce / Apply to a new region

# 1) polygon-TIF matching + spectral means
python extract_overlap_means.py
# 2) v2 geometry-aware feature extraction
python extract_texture_v2.py
# 3) merge with MS AI4Good labels if available
python merge_ms_labels.py
# 4) run v7 classifier
python analyze_damage_v7.py
# 5) or reuse existing model:
from joblib import load
m = load('analysis_v7/damage_model_v7.joblib')
X = your_polygon_features[m['features']]
Xs = (X - m['scaler'].mean_) / m['scaler'].scale_
proba_lr = 1/(1+np.exp(-(Xs @ m['lr'].coef_[0] + m['lr'].intercept_[0])))
proba_gbt = m['gbt'].predict_proba(Xs)[:,1]
category = np.where(proba_gbt >= m['threshold_gb'], 'full',
           np.where(proba_lr >= m['threshold_lr'], 'partial', 'minor'))
