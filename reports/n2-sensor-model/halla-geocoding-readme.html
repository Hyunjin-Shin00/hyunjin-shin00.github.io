종류값단위용도
amp진폭 = √강도DN (~15,000)원본 I/Q 크기 척도. "원본값"이 필요할 때
int강도 = 평균(I²+Q²), 멀티룩 4×3DN²통계·평균 계산 (선형 평균이 맞는 물리량)
dB10·log₁₀(강도)dB (상대)시각화. σ⁰가 아님 — 보정상수 없어 씬 간 절대 비교 불가
locinc국지입사각 (DEM 경사면 기준)도지형이 만든 밝기 보정(γ⁰), 입사각 정규화

amp² = int, 10·log₁₀(int) = dB — 세 밝기 파일은 같은 정보의 다른 척도다. 스택 파일의 dBn은 공통 유효화소 중앙값을 0 dB로 맞춘 정규화본이다.

7. 사용 시 주의

  • LV1A SSC 레이아웃 결함. h5의 S01/SBI가 (2·라인, 샘플) int16으로 잘못 선언돼 있고 실제로는 스트립 앞 절반만 담고 있다. n2reader.read_slc()가 평탄버퍼 규칙(reshape(-1, 5193, 2))으로 읽는다. 다른 리더로 읽으면 잡음이 나온다.
  • dB는 상대값. Level 1A에 보정상수가 없어 σ⁰가 아니다. 씬 간 밝기 비교는 dBn 또는 별도 정규화 후에. 절대 σ⁰는 Level 1D 제품이 필요.
  • mask == 0만 분석에 사용. 산악이라 레이오버가 2~7 %, 그룹 전 씬 공통 유효화소는 AR 45 % / ALDR 37 %.
  • 20240229는 적설 100 %(Sentinel-2 확인). 위치는 맞췄으나 산란 특성이 달라 밝기 시계열에서 제외 권고.
  • DEM 오프셋 북 +4.8 m는 12씬 공통 → 상대정합엔 무해, 절대에만 남음. 정사영상 GCP나 CR로만 제거 가능.
  • 미세정합본(_coreg)은 데이터 기반 이동이 더해진 것. 절대위치 논의에는 baengnokdam\의 원본 타일을, 시계열엔 output\을 사용.
  • 대류권은 표준대기 모델(±0.2 m). SaTReC 처리기가 이미 뺐는지 불명 → 순수 계기편향은 30~32 m 범위.
