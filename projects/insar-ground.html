InSAR 기반 지반침하 · 산사태 모니터링Ground Subsidence & Landslide Monitoring with InSAR

2025.11 – 진행 중 · 주 담당Lead · 진행 중Ongoing
InSARSBASPS-InSARISCE2PyGMTSAR

밀리미터 단위 지표 변위를 위성으로 잡아내는 InSAR 처리 역량을 사내에 구축했다. SBAS와 PS 두 계열을 모두 구현하고 서로 교차검증했다.Built in-house InSAR capability for millimetre-scale surface displacement — implementing both SBAS and Persistent Scatterer approaches and cross-validating them.

배경 · 목표Background

  • 산사태와 지반침하를 사후 확인이 아니라 선제적으로 감시하려면 InSAR이 필요했다.
  • 국립공원 관리기관의 SAR 산사태 모니터링 과제를 계기로 내부 기술 역량 구축을 시작했다.
  • 이후 광역 지자체 지반침하 사업과 AI 기반 위성정보 활용 과제로 수요가 확대됐다.
  • Detecting landslides and subsidence before they become incidents requires interferometry, not after-the-fact imagery.
  • A landslide-monitoring request from a national park authority was the trigger to build the capability in-house.
  • Demand then grew to a metropolitan subsidence programme and an AI-based satellite analytics project.

방법Method

  • PyGMTSAR 기반 SBAS InSAR 구현 — 네팔·파키스탄·경주 지역 시계열 변위 분석.
  • ISCE2 프레임워크로 COSMO-SkyMed(X-band) InSAR 처리 파이프라인 구축: SLC 정합 → 간섭도 생성 → coherence 산출 → 필터링 → 지오코딩.
  • snaphu로 위상 언래핑(phase unwrapping) 수행.
  • isce2 stackSentinel 기반 PS-InSAR 파이썬 구현 — 부산 지역 적용.
  • SBAS와 PS 속도장을 교차 비교해 서로의 신뢰도를 검증했다.
  • 차세대소형위성 2호(N2) 메타데이터를 CSK 포맷으로 변환해 ISCE2에 투입하는 코드 개발.
  • SNAP Offset Tracking으로 대변위(사구 이동·빙하) 탐지 테스트.
  • SBAS InSAR with PyGMTSAR — time-series displacement over Nepal, Pakistan and Gyeongju.
  • A COSMO-SkyMed (X-band) InSAR pipeline on ISCE2: SLC coregistration → interferogram → coherence → filtering → geocoding.
  • Phase unwrapping with snaphu.
  • A Python PS-InSAR implementation on top of isce2 stackSentinel, applied to Busan.
  • SBAS and PS velocity fields cross-compared to validate each other.
  • Code to translate NEXTSat-2 (N2) metadata into CSK format so ISCE2 could ingest it.
  • SNAP Offset Tracking tested for large displacements such as dune migration and glacier flow.

결과Results

  • CSK InSAR 처리 파이프라인 구축 완료 및 결과 보고서 작성
  • 네팔 · 파키스탄 · 경주 SBAS 지표 변위 지도 생성
  • 부산 PS-InSAR LOS 속도장 및 침하 핫스팟 시계열 도출 (Sentinel-1, 2021–2023, 약 29만 PS)
  • SBAS–PS 속도 교차비교로 두 기법의 일치도 정량 확인
  • N2 → CSK 메타데이터 변환 코드 개발 완료 (이후 전용 센서모델 구현으로 발전 — 아래 별도 프로젝트 참조)
  • A working CSK InSAR pipeline, with a delivered results report.
  • SBAS displacement maps for Nepal, Pakistan and Gyeongju.
  • Busan PS-InSAR LOS velocity field and subsidence-hotspot time series (Sentinel-1, 2021–2023, ~293k persistent scatterers).
  • Quantified agreement between SBAS and PS velocities via direct cross-comparison.
  • Working N2 → CSK metadata conversion, which later grew into a dedicated sensor model — see the separate project below.

배운 점 · 한계What I learned · Limitations

  • InSAR 전체 워크플로우(SLC → 간섭도 → 언래핑 → 변위)를 도구에 기대지 않고 단계별로 이해했다.
  • ISCE2 · PyGMTSAR · SNAP의 장단점을 실제 처리 경험으로 비교할 수 있게 됐다.
  • 위성 메타데이터 포맷의 복잡성과 SAR 궤도·기하 파라미터 체계를 깊게 파고들었다.
  • 한계: N2 위성 데이터의 품질 이슈(coherence 부족)로 InSAR 최종 검증까지는 가지 못했다.
  • Understood the full chain — SLC to interferogram to unwrapping to displacement — step by step rather than as a black box.
  • Can now compare ISCE2, PyGMTSAR and SNAP from actual processing experience, not documentation.
  • Went deep into satellite metadata formats and SAR orbit/geometry parameter conventions.
  • Limitation: N2 data quality (insufficient coherence) stopped the final InSAR validation short.
